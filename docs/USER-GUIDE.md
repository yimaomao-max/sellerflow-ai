## 1. 界面导览

```
┌──────────────────────────────────────────────────────────────────────────┐
│  SF SellerFlow AI    [N商品] [错误] [警告] [✓可导出]    导入 导出 校验 设置 │
├──────────────────────────────────────────────────────────────────────────┤
│  搜索框 │ 筛选 │ 新建 │ AI批量 │ 插件演示 │ 删除选中                          │
├──────────────────────────────────────────────────────────────────────────┤
│  □ │状态│ 标题 │ 描述 │ 价格 │ SKU │ 评分 │ 翻译 │ 状态                     │
│  ... 表格行，点击行打开右侧抽屉 ...                                        │
├──────────────────────────────────────────────────────────────────────────┤
```

| 区域 | 作用 |
| --- | --- |
| 顶部状态芯片 | 实时统计商品数、校验错误/警告；无错误时显示「可导出」 |

| 批量编辑条 | 仅在有选中行时出现 |

## 2. 导入商品

### 2.1 从 CSV 导入

1. 点击 **导入** → 选择 `.csv` 文件（UTF-8 推荐）  
2. 系统用第一行作表头，**自动映射**常用列名  
3. 无法映射的列进入每行的 `extras`，导出时可选带回  

**提示**

- 同一文件可多次导入，新行会 **追加** 到列表（顶部按钮）或 **替换**（空状态下的导入，见实现差异：主工具栏为追加）  
- 若缺 `handle`，会根据标题 **自动生成** URL 友好 slug  

### 2.2 示例数据

空列表时点 **载入示例数据**，获得 3 条中英文混合的演示商品，适合第一次体验 AI 与校验。

### 2.3 插件演示入库

访问 **/extension-demo**，模拟浏览器插件采集确认后写入 localStorage，回到首页刷新即可看到新商品（与 CSV 导入共用存储键 `sellerflow.products.v1`）。

## 3. 编辑与批量操作

### 3.1 行内编辑

在表格中直接修改 **标题、描述、价格** 等列，失焦即保存到 localStorage。

### 3.2 详情抽屉

点击任意行打开抽屉，可编辑：

- 基础字段：Handle、标题、描述、价格、原价、SKU、品牌、类目、标签、状态  
- **翻译**：按语言维护 `title` / `description`  
- **分层字段**（高级）：`sourceTitle`、`aiTitle` 等，用于对照供应商原文与 AI 稿（采纳 AI 时可一键覆盖当前标题）

### 3.3 批量编辑

1. 勾选一行或多行  
2. 在底部 **批量编辑条** 选择操作：  

| 操作 | 适用场景 |
| --- | --- |
| 设置为 | 统一改成同一品牌名、同一状态 `draft` |
| 查找替换 | 批量把 `Supplier` 换成你的店铺名 |
| 添加前缀/后缀 | 给标题加 `[NEW]` 或季节标签 |
| 转大写/小写 | 规范 SKU |
| 去除首尾空格 | 清理供应商多余空格 |
| 清空字段 | 批量清空标签等 |
| 清空某语言翻译 | 重新跑 AI 翻译前重置 |

3. 点击 **应用**；可 **取消选择** 清空勾选。

## 4. AI 批量处理

入口：**🤖 AI 批量处理**（无选中时默认对当前筛选结果全部处理；有选中时仅处理选中项）。

### 4.1 模拟模式（默认）

未配置 API Key 时自动使用 **mockAi**：

- 标题：拼装品牌 + 卖点 + 类目风格字符串  
- 翻译：词典替换 +「模拟翻译」标记  
- 描述重写：结构化 bullet 列表  

适合演示、答辩、写 UI 测试，**请勿直接用于正式上架**。

### 4.2 真实模型

在 **设置** 中填写 Key 并关闭模拟模式，或在服务端配置 `.env.local`。

| 任务 | 你会得到什么 |
| --- | --- |
| 生成标题 | 更新 `title`，并写入 `aiTitle` 供对照 |
| 翻译 | 合并到 `translations[语言代码]` |
| 重写描述 | 更新 `description` / `aiDescription` |

处理是分批进行的，顶部会显示 **AI 处理中…** 进度；失败时 Toast 提示原因（常见：额度不足、模型名错误、网络超时）。

### 4.3 建议参数

| 场景 | 建议 |
| --- | --- |
| 英文店主店 | 标题语言选 `en`，先 title 再 translate 到 `es`/`de` 等 |
| 中文货源英文化 | 源为中文时先 `rewrite` 再 `title` 英文化 |
| 大批量 | 先选 5 条试跑，满意再全选 |

## 5. 校验与评分

点击 **✓ 校验** 打开面板。

### 5.1 问题级别

| 级别 | 含义 | 导出 |
| --- | --- | --- |
| **Error** | 不满足 Shopify 常见硬性要求 | 默认 **不导出** 该商品 |
| **Warning** | 建议优化，不阻断 | 可导出，但应人工确认 |

### 5.2 完整度评分（每商品 0–100）

评分由检查清单推导，例如：

- 标题存在且 ≤255 字符  
- 标题长度建议 ≥20  
- 描述建议 ≥30 字符  
- 价格为正数  
- SKU 存在、无空格、不重复  

表格 **评分** 列可快速扫一眼整店质量。

### 5.3 问题清单

面板内可复制/查看全部 issues，按商品 ID 聚合，便于分工修改。

## 6. 导出 CSV

1. 点击 **导出**  
2. 默认规则：**仅包含无 Error 的商品**（与顶部「可导出」一致）  
3. 若某语言已有翻译，导出列会包含对应 `title:xx` 与描述列  

**导入 Shopify**

1. Shopify Admin → Products → Import  
2. 上传导出文件  
3. 按向导映射列（通常 Title / Body / Variant Price / SKU 已对齐）  

> MVP 不处理图片 URL 批量上传、多 Variant 矩阵；复杂变体请在 Shopify 内二次编辑或使用后续版本。

## 8. FAQ

**Q：刷新页面数据会丢吗？**  
A：不会。商品列表与设置存在浏览器 localStorage。清除站点数据会重置。

**Q：能否多人协作？**  
A：当前 MVP 不支持。云端账号与 Supabase 同步见 `docs/TECH-ARCHITECTURE.md` 目标态。

**Q：AI 请求报 502？**  
A：检查 Base URL 是否以 `/v1` 结尾、模型名是否存在、Key 是否有效；可先开模拟模式确认 UI 流程。

**Q：导出为空？**  
A：很可能全部商品仍有 Error。打开校验面板，先修红色项。

**Q：支持 Excel (.xlsx) 吗？**  
A：请在 Excel 中 **另存为 CSV UTF-8** 再导入。

**Q：localStorage 有大小限制？**  
A：通常约 5MB。上千行大 CSV 建议未来版本走服务端；当前适合中小批量测品。
