## 1. 产品概述

SellerFlow AI 把供应商商品页面转化为可审核、可编辑、可发布的 Shopify 商品资料。

核心工作流：

```
供应商商品页面 → 插件采集 → AI 整理 → 变体/价格处理 → 质量检查 → 用户审核 → Shopify CSV
```

产品原则（所有需求必须遵守）：

- **P1 原始数据不可变**：AI 生成结果与用户修改结果分开保存，任何字段可对照、可回退。
- **P2 人工审核优先**：AI 只整理和建议，不自动发布；所有输出经用户确认。
- **P3 采集由用户触发**：插件不自动抓取、不收集浏览历史、不绕过登录/验证码/付费墙。
- **P4 先 CSV 后 API**：V1 只输出 Shopify CSV，不做平台 API 写入。
- **P5 不做 ERP**：订单、库存、物流、采购、财务一律不在范围内。

## 2. 目标用户与场景

### 2.1 用户画像

| 画像 | 描述 | 高频场景 | 付费动机 |
| --- | --- | --- | --- |
| PM-A Shopify 小卖家 | 英语市场，1 个店，每周上架 5–20 个新品 | 从 AliExpress 找品 → 上架 | 节省写 listing 的时间 |
| PM-B Dropshipping 卖家 | 批量测品，每天上新 10–50 个 | 批量采集 → 改标题 → 算价 → 导入 | 批量处理 + 变体不出错 |
| PM-C 代运营/服务商 | 为客户店铺整理资料 | 多客户多品类，要求语气统一 | 品牌模板 + 完整度保证 |

### 2.2 核心用户旅程（V1 验收路径）

1. 用户注册登录 Web 工作台，安装插件并登录同一账号。
2. 打开 AliExpress 商品页 → 点击插件「Capture」。
3. 插件展示识别结果预览，用户勾选图片、确认/修正字段 → 保存。
4. 回到工作台，看到新商品（source + draft）。
5. 一键 AI 整理（英文标题、描述重写/翻译）→ 逐字段对照审核。
6. 处理变体（选项标准化）→ 设置价格规则 → 查看完整度评分。
7. 修复所有错误 → 导出 Shopify CSV → 导入 Shopify 后台。

**首次采集到导出目标 ≤ 3 分钟（单个商品）。**

## 3. 版本范围

### 3.1 V1 必须实现（P0）

Chrome 插件、AliExpress/Alibaba/CJdropshipping 采集、字段提取与预览、图片选择、原始数据保存、商品工作台（列表/草稿编辑/原始对照）、AI 标题生成、AI 描述生成、英文翻译与本地化、变体整理、价格加价计算、质量检查与完整度评分、Shopify CSV 导出、注册登录、额度管理。

### 3.2 V1 不实现（明确排除）

订单/库存/物流/仓库/采购/财务管理、多平台自动发布、Shopify API 写入、全网自动搜索采集、移动端、绕过反爬、AI 自动发布。

### 3.3 后续版本（本文档只留接口，不做需求细节）

- P1：Shopify OAuth 与商品草稿 API 写入；批量 AI 任务；品牌语气模板；eBay/Etsy/TikTok Shop CSV。
- P2：团队工作区、代理商多客户管理、更多供应商站点。

## 4. 功能需求

### F1 Chrome 插件（Manifest V3）

#### F1.1 页面识别

- 插件在受支持的商品详情页显示「可采集」状态（popup 徽标 + 页面角标）。
- V1 支持站点：AliExpress（`aliexpress.com/item/*`）、Alibaba（`alibaba.com/product-detail/*`）、CJdropshipping（`cjdropshipping.com/product/*`）。
- 站点支持由「站点适配器」决定，适配器 key + 版本号上报，便于独立修复（详见技术文档）。
- 不支持的页面：popup 显示明确原因（"该页面不是受支持的商品详情页"），不提供猜测性采集。

**验收**：V1 目标站点样本 20 个商品页面，采集成功率 ≥ 95%；不支持页面 100% 给出明确错误而非错误数据。

#### F1.2 采集与字段预览

用户点击「Capture」后，popup 展示提取结果，允许在发送前修改：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| title | 是 | 商品标题 |
| description | 是 | 描述（含 HTML 时保留原文） |
| price | 是 | 现价（数值） |
| original_price | 否 | 划线价 |
| currency | 是 | 币种 |
| images[] | 是 | 图片 URL 列表，支持勾选与拖拽排序，默认全选、上限 10 张 |
| options / variants | 否 | 选项名+值+SKU+价差的结构化 JSON |
| attributes | 否 | 规格（材质、尺寸、重量等）键值对 |
| source_url | 自动 | 当前页面 URL |
| source_site | 自动 | 适配器 key |

- 任一字段提取失败：该字段标记红色「未识别」，允许手动填写后继续。
- 关键字段（title/price）全部失败时阻止发送并提示。

**验收**：预览页可编辑任意字段；发送的数据与预览一致。

#### F1.3 变体预览

- 展示选项矩阵（如 Color × Size），每个变体含 SKU、价差、图片（若有）。
- 检测常见脏数据：重复变体、空 SKU、缺图变体、选项值带乱码/表情符号，标记提示但允许发送。

#### F1.4 发送至工作台

- 未登录：popup 引导登录（打开 Web 登录页）。
- 额度不足：显示当前套餐与剩余额度，引导升级。
- 网络失败：本地队列暂存，恢复后自动重试（上限 3 次），失败可手动重发。
- 成功：toast 显示「已发送到工作台」+ 工作台链接。

#### F1.5 插件 UI 状态机

`未登录 → 已登录/未识别页面 → 可采集 → 采集中 → 预览（可编辑） → 发送中 → 成功/失败`

#### F2 Web 工作台

#### F2.1 注册与登录

- Supabase Auth：邮箱魔法链接 + Google OAuth。
- 新用户自动创建 workspace（个人版），默认 Free 套餐额度。
- 引导流程：注册后首屏展示「安装插件 → 采集第一个商品」两步引导。

**验收**：注册 → 登录 → 看到空工作台引导页，全程 ≤ 1 分钟。

#### F2.2 商品列表（首页）

- 每行：缩略图、标题（draft 优先，无则 source）、来源站点、状态、完整度评分、价格、更新时间。
- 状态：`captured（已采集） → processing（AI 处理中） → ready（待审核） → exported（已导出） / error`。
- 筛选：状态、来源站点、评分区间、搜索（标题/SKU）。
- 批量操作：AI 整理、导出 CSV、删除（二次确认）。
- 排序默认：更新时间倒序。

**验收**：100 条记录下列表加载 ≤ 2s；筛选与搜索正确。

#### F2.3 草稿编辑器（核心页面）

三栏布局：**原始数据 | AI 生成 | 最终内容**。

- 字段级操作：采纳 AI（←）、保留原文、手动编辑、恢复历史版本。
- 每个字段显示来源标记：`source / ai / manual`。
- AI 未运行的字段显示原始值；AI 结果未采纳前不进入最终内容。
- 保存为草稿态（自动保存，防抖 2s），支持撤销最近 10 步。
- 编辑历史：每次变更记录 field、from、to、source、时间（保留 30 天）。

**验收**：任意字段可完成「AI 生成 → 手动修改 → 恢复 AI 版本 → 恢复原始值」闭环，数据不丢失。

#### F2.4 AI 内容处理

| 功能 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| 英文标题生成 | 原标题+属性+品类 | 英文标题 60–120 字符 | 含核心关键词与规格；可重跑 |
| 描述重写 | 原描述 | 结构化英文描述（要点+规格+场景） | 不虚构参数；保留原始规格数值 |
| 翻译/本地化 | 任意字段 | 目标语言文本 | 本地化而非直译；术语表生效 |
| 批量处理 | 多个商品 | 同上 | 进度可见、失败可单条重试 |

- 品牌语气设置（F2.10）影响全部生成结果。
- 所有 AI 结果默认不覆盖最终内容，必须用户采纳（原则 P2）。

**验收**：单商品标题+描述生成 ≤ 15s（P95 ≤ 30s）；结果保存至 generated_contents 并可回溯。

#### F2.5 变体管理

- 选项标准化：选项名映射（如 `Color/Colour/颜色 → Color`），选项值清洗（去表情、去促销词如 "China Only"）。
- 变体重命名、批量替换（查找替换作用于选项值）。
- 变体筛选/禁用：不需要上架的变体可禁用（导出时排除）。
- 变体级价格：可覆盖商品价，显示与主价格的关系。

**验收**：含 2 选项 × 10 变体的商品可完成标准化+禁用+导出；变体数据为结构化 JSON（原则 P1）。

#### F2.6 价格工具

- 输入：成本价（默认取 source price，可改）、运费、加价方式（比例 % / 固定金额 / 目标毛利 %）。
- 输出：建议售价，公式透明展示，可手动覆盖（覆盖后标记 manual）。
- 心理定价选项：以 .99 / .95 结尾。
- 原始成本价永不被 AI 修改（原则 P1）。

**验收**：三种加价方式计算结果与手算一致；成本字段变更留痕。

#### F2.7 图片管理

- 展示采集图片，勾选上架图片、拖拽排序（第 1 张为主图）。
- 基础检查：分辨率 < 500px 警告、重复图片去重、缺失 alt 提示。
- V1 不做图片编辑/裁剪/水印。

#### F2.8 质量检查与完整度评分

评分 0–100，规则分级：

| 级别 | 规则（V1） |
| --- | --- |
| Error（-15/项） | 缺标题/描述/价格/SKU；标题 > 255 字符；价格 ≤ 0 或非数字；SKU 重复；无可用图片；无可用变体（源有变体时） |
| Warning（-5/项） | 标题 < 60 字符；描述 < 200 字符；图片 < 3 张；主图分辨率低；选项值含异常字符；成本未确认 |

- 100 分 = 可直接导出；列表与编辑器头部实时显示评分。
- 每个问题点击可跳转到对应字段。

**验收**：错误修复后评分实时更新；导出前强制展示检查结果（Error 存在时需确认才可导出）。

#### F2.9 导出

- Shopify 商品 CSV（官方模板列），一个 draft 一行 + 变体行。
- 支持勾选多个商品合并导出；禁用变体不导出。
- 导出文件保留 30 天，可在「导出历史」重新下载。
- 导出后 draft 状态标记 exported。

**验收**：导出 CSV 可被 Shopify 后台导入且变体、图片、价格正确（用测试店铺验证）。

#### F2.10 设置

- 品牌语气：品牌名、语气（professional/casual/luxury/...）、目标市场、关键词偏好、禁用词。
- 默认价格规则。
- 额度：显示套餐、本月采集次数、AI 生成次数、升级入口。
- 账号：登出、删除账号（删除全部数据）。

## 5. 数据需求（摘要，详见技术文档）

- `source_products.raw`（不可变）与 `product_drafts`（可变）分离。
- 变体为结构化 JSON（options 数组 + variants 数组），禁止存纯文本。
- `generated_contents` 记录每次 AI 生成：字段、引擎、prompt 版本、内容、采纳状态。
- `quality_checks` 存最近一次检查结果；`usage_events` 支撑额度统计。
- 图片存 URL 引用（V1 不转存图片文件）。

## 6. 非功能需求

| 项 | 要求 |
| --- | --- |
| 性能 | 工作台首屏 ≤ 2s；插件采集 ≤ 3s；AI 单字段 ≤ 15s |
| 可用性 | 核心 API 99%（早期尽力而为）；失败任务可重试 |
| 隐私 | 只读取当前激活商品页所需数据；隐私政策页说明采集范围；不卖数据 |
| i18n | 界面支持英文（默认）与中文 |
| 浏览器 | Chrome 110+（MV3）；工作台支持 Chrome/Edge 最新两个大版本 |
| 安全 | RLS 按 workspace 隔离；插件 token 与会话绑定 |
